This is a skeleton. None of these sections has been agreed yet. The structure
follows the DSSC Blueprint rulebook model, cut down to what a pilot needs.

Mark every rule as one of:
- **enforced**: checked on every request by the connector (see
  [../docs/enforcement-capabilities.md](../docs/enforcement-capabilities.md));
- **audited**: logged, and checked afterwards;
- **contractual**: an obligation of the parties that no system checks.
